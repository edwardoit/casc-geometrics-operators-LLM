The run

49,215 steps of 72,960 tokens, 13.96 hours on 6 RTX PRO 6000, no errors and no restarts. Learning rate 6e-4 with a 2,000-step warmup, constant up to 3.05 B tokens, then linear decay to zero. In the last 160 M tokens the windows grow from 96 to 384 tokens.

How the machine computes

Each block updates the state in two steps. First the recurrent memory and the communication attention produce x⁺. Then seven stages in cascade deform it: at every stage a router decides, position by position, how much weight to give to the null slot and to the five operators of that stage's family.

x→signed-simplex GRU memory→attention A→x⁺→stage k: h = norm(x), u = SiLU(hPg)⊙hP↑→router πk over 1 null slot + 5 operators→d = Σ πj opj(u)→x ← x + ψ(d)P↓↻ 7 times

All measurements in this section come from the final checkpoint, on validation windows stratified by domain. Closing a stage means forcing π₀ = 1, that is d = 0: the state passes through unchanged. The cost is the CE that is lost.

Stages cover for each other

Closing a whole block costs much more than the sum of its seven stages closed one at a time: when a stage is missing, the following ones re-read the state and recover the correction.
